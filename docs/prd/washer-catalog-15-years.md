# 최근 15년 한국 내수 세탁기 모델 카탈로그 확장 PRD

## 1. 목적과 상태

브랜드·제조국 제한 없이 최근 15년 동안 한국에 판매된 내수 세탁기를 가능한 한 넓게 수집하고, 출처와 기간 근거를 함께 Neon DB에 저장합니다. 해외 제조·수입 모델도 국내 판매 근거가 있으면 포함합니다. 수집 대상을 소수 시연 모델로 제한하지 않습니다. 세탁·건조 예상 소요시간 및 남은 시간 예측은 제품 범위에서 제외합니다.

사용자가 전 세계 수집을 중단하고 한국으로 전환하도록 지시했으며, “한국에 판매된 내수 모델(해외 제조 포함)”이라고 범위를 확정했습니다. 이 개정이 기존 전 세계 수집 범위를 대체합니다. 전 세계 수집 작업은 안전하게 중단하고 체크포인트를 보존하며, 이미 적재된 기존 데이터는 삭제하지 않습니다. 국내 검색은 한국시장 근거가 있는 데이터만 대상으로 합니다.

- 요청일 및 기준일: 2026-11-11, 한국 시간
- 기간: 2011-11-11~2026-11-11, 양 끝 포함. 실행일에 따라 몰래 이동시키지 않습니다.
- 상태: 사용자 구현 승인 완료 (2026-11-11), 구현 세션에서 수집·검증·Neon 적재 진행
- 기존 승인된 백엔드 P0 작업은 계속 진행합니다. 이 문서는 카탈로그 대규모 수집 확장 범위를 추가합니다.
- 한국의 15년 전체 판매 모델 목록을 확보했다고 아직 확인하지 못했습니다. 공식 등록목록과 과거·단종 자료의 범위를 추적하고 자료원의 공백을 명시합니다.

## 2. 수집 대상과 기간 판정

- 한국에 판매된 모든 브랜드의 가정용 일반·드럼·소형·휴대형·세탁건조 겸용 세탁기를 포함합니다. 독립 건조기·식기세척기는 제외합니다. 한국 브랜드의 해외 전용 모델은 국내 판매 근거 없이는 제외합니다.
- 상업용 세탁기도 발견 시 별도 `use_type=commercial`로 보존합니다. 가정용 코스 추천에 자동 사용하지 않습니다.
- 출시가 2011년 이전이어도 기간 중 국내 판매·유통 근거가 있으면 포함합니다. 기간 중 출시 모델만 모으는 것으로 대체하지 않습니다. 기간 포함 기준은 국내 판매이고 생산기간은 별도 주장으로 보존합니다.
- 공식 생산 시작·종료 구간이 기간과 겹치거나 기간 내 제조 사실이 확인되면 `production_confirmed`로 분류합니다.
- 생산 시점 대신 출시일·판매일·인증일만 확인되면 각각의 날짜 종류를 보존하고 `market_evidence_only`로 분류합니다. 생산 확인으로 바꾸지 않습니다.
- 연도만 알려진 경계 모델이나 시점이 불명확한 모델은 후보 DB에 `date_uncertain`으로 보존하고 확정 포함 수에서 분리합니다.
- 미래 출시 예정·기간 밖 생산이 확정된 모델은 대상 확정 목록에서 제외하되 제외 사유를 남깁니다.
- 한국시장·기간 적합성을 `confirmed`, `candidate`, `excluded`로 구분합니다. 생산확정/시장근거/날짜불명 상태는 별도 근거 분류이며, 생산기간 미확인만으로 국내 판매 모델을 제외하지 않습니다. 등록 완료일을 실제 판매 시작일로 바꾸지 않습니다.
- 15년 국내 전체 모델 수를 모르면 전체 대비 수집률을 만들지 않습니다. 분모가 확인되는 개별 출처의 목록 대비 처리율만 보고합니다.

## 4. 자료원과 수집 전략

다음은 조사할 공식 자료원이며, 접근 가능성과 과거 데이터 보유 범위는 구현 중 확인합니다.

1. 한국에너지공단 효율관리제도 일반 세탁기 목록: `https://eep.energy.or.kr/certification/certi_list_298.aspx`.
2. 한국에너지공단 효율관리제도 드럼 세탁기 목록: `https://eep.energy.or.kr/certification/certi_list_299.aspx`.
3. 발견된 모든 브랜드의 국내 공식 제품·단종제품·지원·설명서·카탈로그 및 국내 수입사 공식 자료로 과거 모델과 국내 판매 기간을 보강합니다.
4. 필요하면 국내 공식 인증 공개자료를 보조 근거로 확인합니다. 신고·인증일과 실제 판매·생산일은 구분합니다.
5. EPREL·미국·캐나다·호주 목록을 대상으로 한 신규 전수 수집은 중단합니다. 기존 원문은 보존하되 한국 판매 근거가 없는 해외 모델을 국내 목록에 혼합하지 않습니다.

2026-11-11 기획 조사 당시 기본 목록 표시는 일반 761건, 드럼 1,032건으로 합계 1,793건이었습니다. 이는 필터·변경·중복·과거 자료 처리 전 신고 건수이며, 15년 전체 고유 모델 수나 실제 적재 건수를 뜻하지 않습니다. 실행 시 목록 총건수·페이지수·옛 기준/단종 조회 범위를 다시 확인합니다.

### 예상 소요시간과 진행 알림

- 기본정보 수집·중복제거·Neon 적재·검증은 전환 시점부터 잠정 45~90분으로 계획합니다. 새 한국 어댑터 구현과 사이트 접근 문제를 포함한 계획 추정이며 실측 보장은 아닙니다.
- 2011년까지의 과거·단종 자료 및 국내 판매 기간을 개별 보강하는 전체 작업은 2~4시간 이상이 될 수 있습니다. 코스별 조합 검증까지 완료되는 시간은 별도입니다.
- 첫 실제 다운로드 속도와 전체 페이지 범위를 확인하면 추정을 갱신합니다. 1시간은 빠른 완료 목표이며 시간이 지났다고 중단하지 않습니다.
- 진행률은 한국 범위 작업 기준으로 재산정하고 실제 수집·중복제거·국내근거확정·DB 적재 건수를 함께 알립니다.

- 접근 가능한 공식 API/CSV 다운로드를 우선하고 페이지 수·총건수·필터·수집시각을 기록합니다.
- 특정 유명 브랜드만 하드코딩하지 않고 공식 목록에서 발견되는 브랜드를 확장합니다.
- 제조사별 임의 모델번호 생성, 와일드카드 전개, 모델명에서 생산연도 추정은 금지합니다.
- 단종 포함 옵션과 페이지네이션을 실제 확인하며 최근 판매 제품만 전체로 취급하지 않습니다.
- 외부 검색 결과와 비공식 자료는 발견 단서로 쓰되 확정 레코드는 공식 근거로 검증합니다.
- 로그인·키·다운로드 제한이 있으면 해당 출처를 막힘으로 기록하고 가능한 다른 출처 수집을 계속합니다. 비공개 접근 우회는 하지 않습니다.
- 대량 수집은 출처별 속도 제한·타임아웃·재시도·백오프·체크포인트를 두고 중단 후 재개합니다.

## 5. 데이터 설계

### 모델 기본정보

브랜드 원문·정규명, 제조사, 정확한 모델명·지역 접미사, 판매지역, 제품 유형, 가정/상업 구분, 용량(원 단위 포함), 모델 식별 출처 및 외부 등록 ID를 보존합니다. 원문은 정규화된 검색 키와 별도로 저장합니다.

### 날짜와 근거

생산 시작·종료·제조 확인일, 시장 출시·판매 종료·인증일을 서로 다른 필드로 저장합니다. 날짜 정밀도(일/월/연도), 근거 URL·문서 페이지, 원문, 수집시각, 자료원 ID, 콘텐츠 해시, 기간 포함 판정과 사유를 저장합니다.

### 수집 및 검증 상태

- 수집 작업·출처별 실행 이력 및 체크포인트
- 원문 후보/정규화 모델/출처 주장 연결
- `catalog_only`, `care_settings_partial`, `recommendation_ready` 상태
- 모델 실존 확인, 생산기간 확인, 코스·설정 확인은 별도 상태
- 서로 다른 출처 충돌과 판단 보류 상태

같은 모델의 여러 출처는 연결하고, 지역별 사양 차이가 있는 모델은 합치지 않습니다. 모델 패밀리·유사 접미사는 관계로만 기록하고 개별 확정 모델을 생성하지 않습니다.

## 6. 기존 데이터·코스와의 호환

- 현재 Neon 모델·코스·설정·사용자기기 ID와 연결을 보존하는 추가형 migration을 사용합니다.
- 같은 원본을 반복 적재해 모델·출처·조합이 늘지 않도록 안정 키와 DB 유일성 제약을 둡니다.
- 카탈로그 기본정보 수집이 기존의 검증된 코스·설정을 null로 덮어쓰지 않게 합니다.
- 모델 존재만 확인된 행은 저장·검색할 수 있지만 안전한 코스 추천에는 사용하지 않습니다.
- `Warm`, `Hot`, `High` 등을 임의의 섭씨·RPM으로 바꾸지 않습니다. 코스별 독립 옵션 목록에서 지원 조합을 무조건 곱해 만들지 않습니다.
- 사용자 수동 프로필은 공용 카탈로그와 분리하며 대량 적재 시 덮어쓰지 않습니다.
- AI 담당 `backend/seed/verified/` 파일은 임의 수정하지 않습니다. 공용 수집 코드와 별도 원문/후보 경로를 사용하고 기존 검증 시드의 호환을 유지합니다.

## 7. 시간 예측 제외

- 세탁·건조 예상시간, 실시간 남은 시간 추정, 시간 기반 최적화는 생성하지 않습니다. 최적화 목적은 기존의 최소 세탁 그룹 수를 유지합니다.
- API에 기존 `duration_minutes` 등이 있으면 파괴적 삭제보다 nullable·사용 중단으로 하위호환을 유지하고 의미를 문서화합니다.
- 공식 원문에 시간값이 있더라도 원문 보존과 앱에 예측값을 제시하는 기능은 구분합니다. 원문 시간을 임의 추천시간으로 전달하지 않습니다.
- 모바일 담당자에게 예상시간 UI·계산 제거 요구를 인계합니다. 모바일 소유 코드는 임의 수정하지 않습니다.

## 8. 구현 순서와 완료 기준

1. 기존 전체 P0 구현과 충돌하지 않는 변경 계획·migration 순서를 확정합니다.
2. 출처별 공개 접근·과거 범위·단종 포함·총건수·필드 조사를 기록합니다.
3. 대량 입력 어댑터와 정규화·기간 판정·중복 통합·오류 격리를 구현합니다.
4. 소규모 검증 배치로 실제 원문과 저장 모델을 대조하고 migration을 격리 DB에서 검사합니다.
5. 가능한 출처의 전체 목록을 수집·적재합니다. 수집 상한이나 샘플 제한이 있으면 해제하거나 명확히 미완료로 기록합니다.
6. Neon에 실제 upsert 후 브랜드·연도·지역·상태별 통계와 임의 표본/충돌/경계 사례를 검증합니다.
7. 반복 적재·중단 재개·기간 경계·접미사 보존·기존 ID 보존·검색 페이지네이션 테스트를 통과합니다.
8. 수집된 국내 출처 범위 완료와 한국 15년 절대 전수 확보를 구분한 보고서를 작성합니다.

완료 보고에는 브랜드별/자료원별 발견·적재 건수, 생산확정/시장근거/날짜불명 수, 코스추천 가능 수, 실패·미접근·과거공백, 실제 DB 검증과 실행 명령을 포함합니다. 고정된 소수 모델 적재로 요청 전체를 완료 처리하지 않습니다.

## 9. 승인 및 문서화

### 사용법 수집 확장 — 사용자 실행 승인 반영

사용자가 모델별 사용법도 함께 수집해 Neon에 저장하고, 시간을 최대한 줄이며, 50% 도달 시 알리도록 지시했습니다. 기존 수집 범위에 다음을 추가합니다.

- 모델별 공식 설명서·공식 사용 지원 페이지를 탐색합니다. URL·문서명·언어·해시·페이지·출처·수집시각과 정확한 적용 모델 관계를 DB에 저장합니다.
- 시작 순서, 세제 투입, 코스 선택, 온도·탈수·옵션 설정, 주의사항, 청소·관리를 근거 페이지와 함께 구조화해 저장합니다. 문서에 없는 항목은 미확인으로 둡니다.
- 동일 설명서는 콘텐츠 해시로 중복 제거해 한 번만 추출합니다. 공통 사용법과 모델별 차이를 분리하고, 설명서가 명시한 적용 모델에만 연결합니다.
- 설명서 미확보·추출 실패·검토 필요·검증 완료를 구분합니다. 링크 연결만으로 구조화 사용법 완료라고 처리하지 않습니다.
- 실제 지원 설정 조합을 문서에서 확인하지 못하면 모델별 코스 추천 가능 상태로 승격하지 않습니다.
- 공식 자료 이용 조건을 확인하고 링크·필요 근거·정규화된 사실을 저장합니다. 원문 전체 재배포를 기본 동작으로 하지 않습니다.
- 모델 목록을 먼저 배치 적재한 뒤 설명서 발견·공통 문서 일회 처리·사용법 배치 적재를 진행합니다. 느린 개별 검색은 재시도 큐로 옮겨 전체 수집을 막지 않습니다.
- 예측시간 제외, 기존 데이터 보존, 정확 모델·지역·옵션 구분은 유지합니다.

진행률은 확정한 한국 내수 대상 목록 N의 스냅샷을 분모로 사용하며 전 세계 전수 대비 비율이 아닙니다. 작업 단계 가중치는 목록 확정 10%, 모델 정규화·DB 저장 25%, 공식 사용법 문서 매칭 20%, 구조화 사용법 추출·DB 저장 30%, 검증·보고 15%로 둡니다. 각 단계는 실제 처리 건수/대상 건수로 계산하고, 문서 미발견은 완료된 사용법으로 세지 않습니다. 공유 문서는 모델 적용 여부 확인 후 각 모델의 진행에 반영합니다. 대상을 새로 발견하면 분모 변경과 진행률 조정을 명시합니다.

전체 가중 진행률이 처음 50%에 도달하면 사용자에게 기본 모델 저장수·설명서 연결수·구조화 사용법 저장수·미확인수와 함께 알리고 작업을 계속합니다. 기본정보와 사용법 완료율도 별도 표시합니다. 1시간은 노력 목표이며 강제 중단 조건이 아닙니다. 자동화 알림 대신 현재 실행 중인 구현 작업의 진행 보고로 전달합니다.

PRD와 수집 규모·한계를 안내한 뒤 사용자가 “ㅇㅋㅇㅋ 바로 가자”라고 승인했습니다. 신규 대량 수집 기능의 구현·수집·검증·Neon 적재·수정·완료 문서화를 추가 승인 없이 진행합니다. 이미 승인된 P0 구현·검증도 계속 진행합니다.
이후 한국 내수 범위로 변경 실행을 지시하고 해외 제조 포함을 확정했습니다. 기존 구현 승인을 이 축소된 범위에 적용하며 반복 승인을 요청하지 않습니다.
실행 오류는 원인/수정 코드와 해결/재발 방지 형식으로 기록합니다. 완료 시 한 줄 요약·실제 기여·기술 선택 이유·기술적 도전과 성장 포인트를 작성합니다. 원격 푸시와 외부 팀 메시지 발송은 별도 지시 범위에 따릅니다.
