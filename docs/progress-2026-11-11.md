# 이우진 백엔드 진행 정리 — 2026-11-11

## 현재 결과

백엔드 1단계와 Neon 연결을 완료했습니다. FastAPI에서 옷과 사용자 기기를 저장·조회하고, Neon 콘솔에서도 저장된 의류 행을 직접 확인했습니다. 모바일 앱은 실행 가능한 상태라고 전달받았으며 실제 백엔드 연결은 아직 검증하지 않았습니다.

## 직접 확인한 결과

### 사용자 Swagger 검증

- 로컬 DB에서 서버 재시작 후 옷장과 등록 기기가 유지됐습니다.
- 옷 이름 수정 후 GET 목록에 수정 결과가 반영됐습니다.
- 삭제 연습용 옷만 삭제되고 기존 의류는 유지됐습니다.
- 예시 세탁기의 표준 코스 1개와 `30℃·low`, `40℃·medium` 조합 2개가 조회됐습니다.
- 존재하지 않는 모델 등록은 `MACHINE_NOT_FOUND`로 차단됐고 기존 기기는 유지됐습니다.
- 예시 시드를 다시 적재해도 모델·코스·설정 수와 기존 ID가 유지됐습니다.
- Neon 연결 후 서버를 재시작했고 `/health/db`가 `database: ok`를 반환했습니다.
- `Neon 연결 확인용 셔츠`를 API로 등록·재조회했습니다.
- Neon 콘솔의 `wardrobe_items` 테이블에서 같은 의류가 보이는 것을 사용자가 확인했습니다.

## 데이터와 환경 구분

- 기본 앱 실행 모드는 `demo`이고 소유자는 서버가 지정하는 `demo-user`입니다. 사용자 인증은 아직 구현하지 않았습니다.
- 연결 대상은 Neon 프로젝트 `fancy-bar-96022343`의 `production` 브랜치입니다. 서비스는 Postgres만 사용합니다.
- 앱은 pooled `DATABASE_URL`, 마이그레이션은 direct `DATABASE_URL_UNPOOLED`를 사용합니다.
- 표준 PostgreSQL URL은 코드에서 psycopg 3 형식으로 변환합니다.
- `.env`와 `.env.local`은 비밀 파일이며 Git에 올리지 않습니다. 공유용은 가짜 값만 있는 `.env.example`입니다.
- 이전 `washwise.db`의 데이터는 Neon으로 자동 이전하지 않았습니다.
- 예시 시드는 로더 검증용이며 공식 상품·세탁기 검증 데이터가 아닙니다.

## 남은 작업

1. **모바일 연결**: 이진영 님의 실행 가능한 앱에 API 계약을 전달하고, 휴대폰에서 접근할 서버 주소를 설정합니다. 실기기의 `127.0.0.1`은 PC 서버 주소가 아니므로 실제 연결 환경에 맞는 주소가 필요합니다.
2. **모바일 전체 흐름 검증**: 앱에서 의류 저장 → 재조회, 모델·코스 조회 → 사용자 기기 등록 → 앱 재실행 후 복원을 확인합니다.
3. **공식 데이터 연결**: 유상진 님의 검증된 상품·세탁기 시드를 합의한 형식으로 받아 적재하고 출처를 확인합니다.
4. **AI 연결**: 제공되는 AI 라우터를 공용 서버에 등록하고 분석 결과 저장 흐름을 검증합니다. AI 분석과 상품 검색은 현재 계약만 있습니다.
5. **다음 개발 단계**: 세탁 그룹 최적화와 현재 설정 적합성 판정은 아직 구현하지 않았습니다. 별도 PRD와 구현 승인 범위로 진행합니다.

## 포트폴리오용 정리

- **한 줄 요약**: 의류·기기 관리 API를 FastAPI로 구현하고 Neon PostgreSQL에 연결해 실제 저장·조회까지 검증한 WashWise 백엔드입니다.
- **기여 범위**: 이우진 담당 백엔드 기반, DB 모델·마이그레이션, 옷장·기기 API, 시드 로더, API 계약, 실행 문서와 검증을 수행했습니다. AI·모바일 구현을 본인 기여로 포함하지 않습니다.
- **기술 선택 이유**: FastAPI는 입력 검증·OpenAPI 공유, SQLAlchemy는 관계·트랜잭션 관리, Alembic은 스키마 재현, Neon은 관리형 PostgreSQL, pytest는 회귀 검증에 사용했습니다.
- **도전과 성장**: 독립 온도·탈수 목록 대신 실제 설정 조합을 저장하고 안정 키·유일성 제약·트랜잭션으로 중복을 방지했습니다. 또한 앱용 연결과 마이그레이션 연결을 분리하고 HTTP 결과를 실제 DB 행과 대조하는 검증 방식을 익혔습니다.
