# 이진영 · Android 앱

React Native·Expo 앱에서 의류 촬영부터 세탁·건조 결과 확인까지 연결한다. Android 실기기에 설치한 APK로 시연한다. [WashWise 개발 명세](../../WASHWISE_SPEC.md)

## 브랜치와 수정 범위

- 브랜치 `codex/mobile-app`에서 `mobile/`을 담당한다. Expo 설정, 앱 의존성, 화면, API 호출부, 앱 테스트와 개발용 응답 예시는 이 폴더에 둔다.
- 의류·라벨 분석 API나 검증 데이터 변경은 [유상진](유상진.md)에게 전달한다.
- 공용 API 응답 형식, 옷장·기기·세탁 계획 API, 저장소 공용 설정 변경은 [이우진](이우진.md)에게 전달한다. 필요한 요청·응답 예시와 화면에 미치는 영향을 함께 보낸다.

## 작업 순서

### 0~1시간 · 앱 착수와 API 예시 확인

- [ ] `mobile/`에서 개발용 응답으로 화면을 먼저 만든다.
- [ ] 이우진이 팀 채팅에 공유한 API 예시에서 사진 업로드, 분석 상태, 출처, 옷장·세탁기·계획·설정 검증 형식을 확인한다. 분석 필드 질문은 유상진에게, 나머지는 이우진에게 채팅으로 남긴다.
- [ ] API를 붙이기 전에 합의한 형식을 개발용 응답에 반영한다. 실기기 검증과 시연은 실제 API에 연결해 진행한다.

### 1~12시간 · P0 화면과 연결

- [ ] 홈에서 의류 등록, 내 옷장, 우리 집 세탁기, 가상 드럼으로 이동할 수 있게 한다.
- [ ] 의류·세탁 라벨을 카메라로 촬영하거나 사진 보관함에서 선택할 수 있게 한다. 촬영 권한을 거부하면 사진 선택이나 직접 입력으로 이어지게 한다.
- [ ] 분석 결과에 동일 제품 여부, 공식 출처, 확인이 필요한 관리정보를 표시한다. 식별이 어려우면 라벨 추가 촬영이나 직접 입력을 안내한다. 업로드·분석에 실패하면 입력을 유지하고 재시도할 수 있게 한다.
- [ ] 옷장 목록과 의류 저장·수정·삭제를 연결한다. 여러 벌을 선택해 드럼에 추가하고 드럼에서 한 벌씩 제거할 수 있게 한다.
- [ ] 세탁기 모델 검색·등록과 지원 코스 조회를 연결한다. 드럼에 담긴 옷 수와 선택한 모델을 표시한다.
- [ ] **세탁 분석 시작** 버튼으로 첫 계획을 요청하고 추천 그룹과 코스를 표시한다.
- [ ] 12시간쯤 Android 기기에서 테스트 사진과 기기 데이터로 분석·저장·세탁 계획 조회를 연결한다. 시연용 공식 데이터는 준비되는 대로 연결한다.

### 12~20시간 · 세탁 결과와 예외 흐름

- [ ] 첫 계획이 나온 뒤 의류 추가·제거, 관리 조건 수정, 세탁기 변경 시 기존 결과를 무효화하고 다시 요청한다. 응답 순서가 뒤바뀌어도 최신 구성에 해당하는 결과만 표시한다.
- [ ] 세탁 그룹, 권장 코스·온도·탈수, 분리 사유, 확인 보류 의류, 건조기 사용 가능 여부와 자연건조 방법을 표시한다.
- [ ] 사용자가 세탁기에서 고른 설정을 직접 입력하면 검증 결과와 수정 이유를 표시한다. 실제 세탁기 조작은 사용자가 한다.

### 20~24시간 · 실기기 검증과 시연

- [ ] Android APK를 빌드해 설치하고, 실기기에서 실제 API를 사용하는지 확인한다.
- [ ] 동일 제품 확인과 라벨·직접 입력 흐름, 여러 벌 분리, 잘못된 설정 검증, 옷을 뺀 뒤 재계산을 확인한다. 권한 거부, 업로드 오류, 앱 재실행 후 옷장 조회도 점검한다.
- [ ] APK 위치와 설치·실행 방법, 실제 API 주소 설정 방법, 확인한 기기와 검증 결과를 팀에 공유한다. 시연에 쓸 앱 화면을 녹화해 팀의 2분 영상에 전달한다.
