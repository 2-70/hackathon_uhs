# 유상진 — AI 분석과 검증 데이터

의류 사진과 세탁 라벨을 구조화하고, 실제 제품과 세탁기 모델에 근거가 있는 데이터를 준비한다. 구현 범위는 [WashWise 개발 명세](../../WASHWISE_SPEC.md)의 P0를 따른다.

## 작업 브랜치와 수정 경로

- 브랜치 `codex/ai-analysis`
- `backend/app/ai/`에서 Gemini 호출, 분석 결과 검증, 상품 카탈로그 조회를 구현한다. AI 라우터는 `backend/app/ai/router.py`에서 제공한다.
- `backend/tests/ai/`에 분석·매칭 테스트와 테스트 전용 응답을 둔다.
- `backend/seed/verified/`에 공식 근거를 확인한 상품과 세탁기 시드 데이터를 둔다.
- [이진영](이진영.md)이 `mobile/`을 맡는다. [이우진](이우진.md)이 나머지 `backend/`와 저장소 루트 공용 파일을 맡는다. 앱 표시 방식은 이진영에게, 라우터 등록·DB 세션·모델·마이그레이션·시드 로더·공용 의존성 변경은 이우진에게 전달한다.

## 구현할 일

| API | 구현 |
|---|---|
| `POST /api/analyze` | 의류 사진과 라벨 사진을 구분해 분석한다. 의류 사진에서는 종류·색상·브랜드·품번 단서를 추출한다. 라벨은 소재·혼용률·세탁 기호·온도·건조 조건 등 읽을 수 있는 값을 구조화한다. |
| `POST /api/products/match` | 품번이나 공식 URL 등 식별 단서로 Neon 상품 카탈로그를 조회한다. 동일 제품 확인, 유사 제품 후보, 검색 결과 없음, 조회 오류를 구분한다. |
| `GET /api/products/{id}/care` | 동일 제품에 연결할 수 있는 공식 관리정보와 출처를 반환한다. 공식 문서에 값이 없는 항목은 추가 확인이 필요한 상태로 표시한다. |

- 모델 응답의 형식과 필드 값을 검증한다. 판독이 어려운 항목은 값 없이 확인 필요 상태를 전달해 앱에서 라벨 추가 촬영이나 직접 입력으로 이어갈 수 있게 한다.
- 필드별로 값, 출처 종류, 확인 상태와 근거를 전달한다. 실물 라벨, 공식 제품정보, 의류 사진 추정, 사용자 입력이 구분되어야 한다. 라벨과 공식 관리정보가 충돌하면 확인할 항목을 표시한다.
- 시연용 상품에는 브랜드, 품번, 공식 상품 URL, 공식 자료에서 확인한 관리 조건과 근거를 기록한다. 동일 제품은 신뢰할 수 있는 식별정보가 일치할 때 확정한다.
- 시연용 세탁기 모델에는 제조사, 정확한 모델명, 공식 설명서 링크, 코스, 함께 설정할 수 있는 온도·탈수 조합과 근거를 기록한다. 이우진과 시드 필드 형식을 맞춘다.

## 24시간 진행 순서

| 시간 | 할 일과 전달 사항 |
|---|---|
| 0~1시간 | AI 분석 작업을 시작한다. 입력 이미지, 제품 식별 단서, 출처·확인 상태와 오류의 응답 예시를 팀 채팅에 공유한다. 이우진이 올린 API 초안을 확인하고 라우터 연결, DB 조회, 시드 형식에서 조정이 필요한 부분을 채팅에 남긴다. |
| 1~8시간 | 이미지 분석과 라벨 판독을 먼저 구현한다. 정상 이미지, 흐릿한 라벨, Gemini 호출 실패를 재현할 수 있는 테스트 응답을 준비한다. |
| 8~12시간 | 세 API와 카탈로그 조회를 연결한다. 공식 데이터가 준비되기 전에는 개발용 데이터로 확인한다. 이우진에게 라우터 등록 위치와 시드 경로를 공유하고, 이진영에게 분석 성공·제품 미확인 응답을 전달한다. |
| 12~20시간 | 상품 일치·유사 후보·검색 결과 없음·조회 오류를 점검한다. 라벨을 읽기 어려운 경우와 의류 사진으로 추정한 정보가 앱에 올바르게 표시되는지 확인한다. |
| 20~24시간 | 공식 출처를 확인한 상품·세탁기 데이터로 실제 Gemini 응답과 Neon 조회가 연결된 시연을 점검한다. 출처, 테스트 결과, 남은 이슈를 공유한다. |

## 완료 기준

- 실제 의류 사진과 라벨을 각각 분석하고, 공식 상품 데이터에 연결되는 경우 출처를 표시한다.
- 유사 후보·미확인 상품·판독 실패를 구분하고, 라벨 추가 촬영과 직접 입력 화면에서 사용할 상태가 앱에 전달된다.
- 확인된 시연용 상품과 세탁기 코스·설정 조합이 Neon에 등록되어 조회된다.
- 분석 응답 형식, 상품 일치 기준, 판독 불가와 호출 실패를 테스트한다. 테스트용 응답은 앱의 실제 시연에서 분리한다.
